## 1. Project Overview

This repository documents my practical work during Week 1 of the Networkwalks Cybersecurity Internship.

The project involved completing six browser-based Security Operations Center (SOC) investigation labs using Wireshark concepts and network traffic analysis techniques.

As a SOC analyst trainee, my objective was to investigate network traffic, identify suspicious activities, reconstruct TCP conversations, detect exposed credentials, recognise brute-force attempts, and investigate suspicious VoIP activity.

Each lab contained 10 tasks, making a total of 60 practical tasks.

## 2. Project Objectives

- Understand network packet analysis.
- Identify suspicious source IP addresses in network captures.
- Reconstruct network conversations using Follow TCP Stream.
- Investigate hidden information within network traffic.
- Recognise HTTP clear-text credential exposure.
- Identify repeated login attempts associated with brute-force activity.
- Investigate suspicious VoIP communications.
- Develop practical SOC investigation and documentation skills.
